# Claude Code × Obsidian 初期設定キット（なりあいさん用）

## 1. このキットは何か
- クライアントのPCに置いて `claude` を起動し、「はじめて」と言うだけで、Obsidianの保管庫・約束（CLAUDE.md）・守りの設定が整うフォルダ
- 今まで台本D節で6ブロックを手で貼っていたものを、`SETUP.md`（AIが読む手順書）に置き換えた
- 人がやるのは、アカウントとインストールの「はい」、Googleの許可、最後の5分だけ

## 2. 当日の流れ
人がやる20分 → キットを置く → 「はじめて」 → AIが進める → 最後に人が5分

### A. ブラウザで人がやる（20分）
1. Google：myaccount.google.com →「セキュリティ」→ 2段階認証をオン
2. claude.ai：お客様のメールで登録 → **Pro**（カードは本人が入力）
3. claude.ai「設定」→「プライバシー」→ **モデル改善に使う設定をオフ**
4. 「設定」→「使用量」→ **追加の使用（上限超えの課金）をオフ**
5. 「設定」→「コネクタ」→ **Gmail・Googleカレンダー・Googleドライブ**をつなぐ（Googleの許可は本人が押す）

### B. インストールを人がやる（15分）
1. claude.ai/download から Claude デスクトップを入れてログイン
2. （保管庫をドライブに置く場合）Googleドライブ（パソコン版）を入れてログイン
3. **Windows**：スタートボタンを右クリック →「ターミナル」を開き、1行ずつ打つ

```
winget install --id Git.Git -e
```

```
irm https://claude.ai/install.ps1 | iex
```

4. ターミナルを閉じて開き直し、次を打つ。番号が出れば成功

```
claude --version
```

**Mac**：ターミナルで次を打つ

```
xcode-select --install
```

```
curl -fsSL https://claude.ai/install.sh | bash
```

### C. キットを置いて「はじめて」
下の3、4のとおり。そのあとAIが進める。

### D. 最後に人がやる（5分）
Claude が最後に読み上げる「人がやること」のとおり（Obsidianで保管庫として開く／ゴミ箱の設定／ファイル復元をオン／Claudeデスクトップで同じフォルダを開く）。

## 3. キットを客のPCに置く2つのルート

**先に決める：** 保管庫を「ドキュメント」に作るか、Googleドライブ（パソコン版）の中に作るか。後から動かすと壊れる。おすすめはGoogleドライブの中（古い版が残る）。

### ルートA（GitHubから）
```
git clone https://github.com/hiro0183/ai-setup-kit.git "会社名_脳みそ"
cd "会社名_脳みそ"
claude
```
※ リポジトリが**公開**のときだけ動く。非公開なら客のPCからは取れない。

### ルートB（USB・ZIP）
1. `dist/ai-setup-kit.zip` をUSBで渡す
2. 「ドキュメント」か Googleドライブ（パソコン版）の中に展開し、フォルダ名を `会社名_脳みそ` にする
3. そのフォルダの中で `claude` を起動する

## 4. `claude` を起動したら
- ブラウザが開く → **サブスクのアカウントでログイン**
- 「APIキーを使いますか」は **「いいえ」**（従量課金の落とし穴）
- 最初の言葉は **「はじめて」** だけ

## 5. 困ったとき
- Obsidianが入らない → obsidian.md から人がダウンロードして入れる
- Googleが答えない → claude.ai の設定 → コネクタで、3つをつなぎ直す
- 許可が出ない・動かない → `.claude/settings.json` の deny を見る（守りの設定が効いている）

## 6. キットの更新のしかた
このフォルダ（`C:\Users\tujid\ai-setup-kit`）を直して commit・push する。客のフォルダには影響しない（導入時に `git remote remove origin` で縁が切れている）。ZIPは作り直して `dist/` に置く。
